## 1. 程序简介

`HSV Test App`（Windows 可执行程序 `test_app_hsv.exe`）是用于验证 HSV（色调/饱和度/明度）三通道调整效果的图像处理工具，支持实时预览与结果保存。无需安装 Python 环境，双击即可运行。

- 输入：图像文件、纯色、内置合成测试图三种来源
- 预览：输入/输出对比、像素级 RGB/HSV 读数、冻结像素、结果导出
- BCSH调整：亮度（B）、对比度（C）、饱和度（S）、色调（H）四种参数，支持全图调整，或仅调整指定色相范围内的像素

## 2. 界面布局

- **I/O Config 页**：输入选择与输出保存设置
- **HSV Config 页**：HSV 调整参数
- **Image Preview 窗口**：图像预览（可移动、浮动、关闭；通过菜单 `View → Preview` 显示/隐藏）
- **状态栏**：处理耗时、保存结果等提示信息

## 3. I/O Config 页

### 3.1 选择输入（三选一）

- **Use File as Input**：从文件加载图像。`Browse` 选择文件、`Reload` 重新加载；下方参数（格式/色彩空间/宽高/帧号）与文件对应
- **Use Specified Color**：指定纯色输入，在输入框填写 `R G B`（0-255，如 `200 128 128`）
- **Use Test Pattern**：使用内置合成测试图，选择图案类型：

  | 图案 | 用途 |
  | ------ | ------ |
  | Rainbow Hue Circle | 圆形色环，覆盖全色相，适合观察色调/饱和度调整 |
  | Rainbow Hue Ramp | 水平彩虹渐变，适合观察色调偏移 |
  | HSV Patches | 色相×明度色块，适合观察分区效果 |
  | Saturation Ramp | 饱和度渐变，适合观察饱和度调整 |
  | Value Ramp | 明度渐变，适合观察对比度/明度调整 |
  | Gray Ramp | 灰阶渐变，适合观察明度（无颜色干扰） |

  - 右侧两个数值框：`Value` 固定明度值（0-255）、`Hue` 固定色调值（0-360），用于部分图案
  - 分辨率由 `Width`/`Height` 决定；切换图案、修改参数或分辨率会自动重新生成

### 3.2 输出设置

- `Output Dir`：结果保存目录（`Open Dir` 可直接打开）
- `Output Format` / `Output Colorspace`：输出格式与色彩空间
- `Swap U/V` / `Swap R/B`：分量交换（勾选后自动重新处理）

## 4. HSV Config 页

### 4.1 基本开关

- `Enable HSV Adjust`：启用/停用 HSV 处理（停用时预览显示原始输入）
- `S Tolerance`（0-0.1）：饱和度保护阈值——低于该值的低饱和像素不会被增色，但减色始终允许。用于保护灰暗、肤色等低饱和区域

### 4.2 Contrast（对比度）

`Contrast Adjust Mode` 选择对比度增益的参考点：

| 模式 | 效果 |
| ------ | ------ |
| `GainAtMid`  | 以中间灰度为锚点：增益>1 时亮部更亮、暗部更暗（对比增强），中灰基本不变 |
| `GainAtZero` | 以黑色为锚点：增益>1 时整体提亮 |
| `GainAtBoth` | 增益<1 时按零点方式压暗，增益>1 时按中点方式提亮 |

- `Contrast`（0-4，默认 1.0）：数值越大对比越强，1.0 为无变化

### 4.3 V / S / H 调整

- **Delta V**（-1~1，默认 0）：整体加亮/加暗
- **Delta S**：饱和度调整量，由 `Saturation Adjust Mode` 决定：
  - `Additive`（加性，-1~1，默认 0）：按差值增减饱和度
  - `Multiplicative`（乘性，默认，0~4，默认 1.0）：按倍数缩放饱和度（1.0 为无变化）
- **Delta H**（-180°~180°，默认 0）：色调整体偏移

### 4.4 指定色调调整

勾选后仅目标色相范围内的像素被调整，其余像素保持不变（不勾选则整幅图调整）：

- **Target Hue Range**：目标色调起止角（0-360，支持跨 0° 环绕）
- **Target Hue Tail**：目标范围边缘向内做平滑过渡，避免边界生硬
- **Target Hue Pad**：向外扩展实际处理范围，扩展部分同样平滑过渡
- **Same Hue Goal**：勾选后色调统一向某个目标颜色变化，适合统一某类物体的颜色

## 5. Preview 预览

- **Preview Type**：
  - `BothInLeft`：左预览同时显示输入与处理结果（勾选 `Show Left Input` 显示输入）
  - `SideBySide`：左右并排，左=输入、右=输出
- **Preview Scale**（10%-100%，默认 50%）：预览缩放。调参时可调低提高响应速度，保存时按原始分辨率输出
- `Show Left Input` / `Show Right Input`：控制对应预览显示输入还是结果
- `Save Left Image` / `Save Right Image`：保存当前预览帧（.yuv + .png）到 `Output Dir`
- 信息行：`Display Size`（显示尺寸）、`Position`（鼠标位置）、`Time Cost`（处理耗时）、`Input Pixel` / `Output Pixel`（输入/输出像素读数）

### 像素冻结

- 鼠标在预览图上移动时，信息行实时显示该像素的坐标与 RGB/HSV 值
- 按**空格键**冻结：预览图上出现十字标记，信息行固定显示该像素读数，便于精确对比

## 6. 参数调试建议

1. **先用测试图**：按要验证的维度选图案——验证色调用 Rainbow 系列，验证饱和度用 Saturation Ramp，验证明度/对比度用 Value Ramp 或 Gray Ramp
2. **冻结像素精确对比**：把鼠标移到关注区域按空格冻结，对比 Input/Output 的 RGB 与 HSV 数值，确认调整幅度是否符合预期
3. **从"小"到"大"调参**：先给较小调整量确认方向，再逐步加大；需要基准时用各参数的 `Reset` 回到中性值
4. **对比度参考点选择**：想让暗部整体变亮用 `GainAtZero`；想让画面更有层次（亮更亮、暗更暗）用 `GainAtMid`
5. **保护低饱和区域**：对肤色、灰暗区域做饱和度增强时，适当调大 `S Tolerance`，避免这些区域被过度增色
6. **指定色调边界**：先用 Tail/Pad=0 确认目标范围选择正确，再逐步加大过渡角度消除边界生硬感；跨 0° 的颜色（如红-品红）记得用环绕范围
7. **性能**：大分辨率图像调参时可调低 `Preview Scale`，确认效果后保存（保存按原始分辨率进行）
