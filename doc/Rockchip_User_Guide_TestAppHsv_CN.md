## 1. 程序简介

`HSV Test App`（Windows 可执行程序 `test_app_hsv.exe`）是用于验证 `HSV/HSI/HSL/HCY/RGB/YCbCr` 等多种模型在调整图像亮度（B）、对比度（C）、饱和度（S）、色调（H）时的效果验证工具，支持实时预览与结果保存。无需安装运行环境，双击可执行程序即可运行。

- 输入：图像文件、纯色、内置合成测试图三种来源
- 处理域：支持 `HSV/HSI/HSL/HCY/HSP/Lch/RGB/YCbCr` 八种处理域，像素读数随处理域自适应
- 预览：输入/输出对比、像素级 RGB/HSV/YUV 三通道读数、冻结像素、结果导出
- BCSH调整：亮度（B）、对比度（C）、饱和度（S）、色调（H）四种参数，支持全图调整，或仅调整指定色相范围内的像素

## 2. 界面布局

- **I/O Config 页**：输入选择与输出保存设置
- **BCSH Config 页**：BCSH（HSV）调整参数
- **Image Preview 窗口**：图像预览（可移动、浮动、关闭；通过菜单 `View → Preview` 显示/隐藏）
- **状态栏**：处理耗时、保存结果等提示信息

## 3. I/O Config 页

### 3.1 选择输入（三选一）

- **Use File as Input**：从文件加载图像。`Browse` 选择文件、`Reload` 重新加载；下方参数（格式/色彩空间/宽高/帧号）与文件对应
- **Use Specified Color**：指定纯色输入，在输入框填写 `R G B`（0-255，如 `200 128 128`，输入值和输入格式匹配）
- **Use Test Pattern**：使用内置合成测试图，选择图案类型：

  | 图案 | 用途 |
  | ------ | ------ |
  | Rainbow Hue Circle | 圆形色环，覆盖全色相，适合观察色调/饱和度调整 |
  | Rainbow Hue Ramp | 水平彩虹渐变，适合观察色调偏移 |
  | HSV Patches dV | 色相×明度色块（12 列色相 × 6 行明度），适合观察 V 调整的分区效果 |
  | HSV Patches dS | 色相×饱和度色块（12 列色相 × 6 行饱和度），适合观察 S 调整的分区效果 |
  | Saturation Ramp | 饱和度渐变，适合观察饱和度调整 |
  | Value Ramp | 明度渐变，适合观察对比度/明度调整 |
  | Gray Ramp | 灰阶渐变，适合观察明度（无颜色干扰） |

  - 右侧两个数值框：`Value` 固定明度值（0-255，默认 255）、`Hue` 固定色调值（0-360，默认 0），用于部分图案（色环/彩虹/HSV Patches dS 使用 Value，饱和度/明度渐变使用 Hue）
  - 分辨率由 `Width`/`Height` 决定；切换图案、修改参数或分辨率会自动重新生成

### 3.2 输出设置

- `Output Dir`：结果保存目录（`Open Dir` 可直接打开）
- `Output Format` / `Output Colorspace`：输出格式与色彩空间（跟随输入自动同步，控件已启用）
- `Swap R/B` / `Swap U/V`：输入分量交换——RGB 输入显示 `Swap R/B`、YUV 输入显示 `Swap U/V`，勾选后自动重新加载（测试图/纯色输入时不可用）

## 4. BCSH Config 页

### 4.1 基本开关

- `Enable BCSH Adjust`：启用/停用 BCSH（HSV）处理（停用时预览显示原始输入）
- `Adjust Field`：选择处理域（8 项，像素读数随处理域自适应）：

  | 处理域/模型 | 计算难度 | 说明 |
  | ----------- | ------- | ---- |
  | HSV | 简单 | 色相/饱和度/明度（三分量最大值） |
  | HSI | 复杂 | 色相/饱和度/强度（三分量均值） |
  | HSL | 简单 | 色相/饱和度/亮度（三分量最值的均值） |
  | HCY | 中等 | 色相/色度/亮度（Rec.601，同 Y 亮度一致） |
  | HSP | 复杂 | 色相/饱和度/感知亮度 |
  | Lch | 复杂 | 亮度/色度/色相（CIELAB），感知相对更均匀且亮/色分离的色彩空间，该模型计算复杂，这里实现仅供参考 |
  | RGB | 中等 | 直接在 RGB 三通道上处理，无需额外色域转换 |
  | YCbCr | 中等 | 直接在 YCbCr 三通道上处理，无需额外色域转换 |

- `S Tolerance`（0-0.1，默认 0.0025）：饱和度保护阈值，低于该值的低饱和像素不会被增色，但减色始终允许。用于保护灰暗、肤色等低饱和区域。
- `Y2R Clip` / `Y2Y Clip` 的详细说明与推荐设置见 4.3

### 4.2 BCSH 参数调整方法

- **Contrast（C）**：对比度调整，取值范围 `[0.0, 4.0]`，默认 `1.0`；由 `ModeC` 决定生效方式：
  - `GainAtMid`（默认）：以中灰为锚点，`C>1` 增强对比、`C<1` 向中灰收敛
  - `GainAtZero`：以黑为锚点，`C>1` 整体提亮、`C<1` 变暗
  - `GainAtBoth`：`C<1` 按零点压暗、`C>1` 按中点增强对比
  - `TanSlant`：正切斜率曲线，取值范围 `[-1.0, 1.0]`，默认 `0.0` 表示不调整
  - `FastStone`（仅 RGB 处理域）：**FastStone Image Viewer** 软件兼容的逐通道灰阶拉伸
- **Brightness（B）**：亮度调整，整体加亮/加暗，由 `ModeB` 决定生效方式：
  - `ModeAdd`（默认）：加性偏移，取值范围 `[-1.0, 1.0]`，默认 `0.0`
  - `ModeMul`：乘性缩放，取值范围 `[0.0, 4.0]`，默认 `1.0`
  - `Rate2Limit`：取值 `[0.0, 2.0]`、默认 `1.0`；小于 `1.0` 向纯黑靠拢、大于 `1.0` 向纯白靠拢
- **Saturation（S）**：饱和度，由 `ModeS` 决定生效方式：
  - `ModeAdd`：加性，取值范围 `[-1.0, 1.0]`，默认 `0.0`
  - `ModeMul`（默认）：乘性，取值范围 `[0.0, 4.0]`，默认 `1.0`——尺度统一，**推荐**
  - `Rate2Limit`：取值 `[0.0, 2.0]`、默认 `1.0`；小于 `1.0` 向灰度靠拢、大于 `1.0` 向全饱和靠拢
  - RGB 处理域专用（灰阶混合，RGB 域 S 恒为灰阶混合）：
    - `MixGray_BT709`: 以 BT.709 系数计算灰度
    - `MixGray_BT601`: 以 BT.601 系数计算灰度 （**FastStone Image Viewer** 软件做法）
- **Hue（H）**：色调，默认 `0°`，由 `ModeH` 选择生效方式：
  - `ModeAdd`（默认）：色相加性平移，带环绕（标准做法）
  - RGB 处理域专用选项 `RotateOnGray`：绕灰轴旋转（参考实现）
  - H 旋转后若出现色相偏移，请在 YCbCr 处理域的 `Y2Y Clip` 选择保色相策略处理（见 4.3）
- **Hue Goal**: 色调参数的作用方式：
  - `SameOffset`（默认）：所有像素统一旋转相同角度，取值范围 `[-180°, 180°]`
  - `SameTarget`：所有像素统一向设定的目标角度旋转，此时 H 为旋转进度百分比，取值范围 `[0, 100]`
- 以上参数的取值范围可通过程序同级目录下的 `test_app_hsv_params.json` 配置文件修改

### 4.3 色彩空间转换与饱和度处理（高级）

数据在 YUV 与 RGB 之间转换（`Y2R Clip`）或 YCbCr 处理域内调整（`Y2Y Clip`、`Norm YUV`）时，越界颜色与饱和度按以下方式处理。该选项为算法开发人员参考使用，**常规使用保持默认即可**。

- **Y2R Clip（YUV→RGB 转换钳位）**：YUV 转 RGB 显示/输出时，超出显示范围的 RGB 值如何钳回：
  - `HardClip`（默认）：逐通道硬钳，简单可靠
  - `SoftClip`：软钳，保持色相、过渡更平滑
  - `ConstHue`：恒定色相等比缩放，颜色不发淡
- **Y2Y Clip（色域处理策略，仅 YCbCr 处理域）**：调整后的 YUV 越界如何处理（统一了原 S 归一化与保色相补偿——H 旋转 / S 增强 / B 超界造成的越界都用所选策略处理）：
  - `HardClip`（默认）：YUV 范围硬钳（逐分量独立，可能偏色）
  - `ClipChroma`：把超出色域的色度压回边界（保持亮度与色相，减少偏色）
  - `ScaleChromaPix`：饱和度按每个像素的色域边界归一化（`S=r/r_max`，任意调整不越界、色相不变，饱和度定义更"满"）
  - `ScaleChromaSec`：饱和度按全局最大边界归一化（绝对比例；越界像素按 HardClip 处理）
  - `CompLumaOnly`：保持色度、调整亮度把颜色拉回色域（保色相，代价是亮度漂移）
  - `CompLumaFirst`：优先调亮度，亮度单独不够时再缩色度（色相严格保持，Y 不足时结果落在色域边界）

### 4.4 指定色调调整

勾选 `Specified Hue Adjust` 后仅目标色相范围内的像素被调整，其余像素保持不变（不勾选则整幅图调整）：

- **Target Hue Range**：目标色调起止角（0-360，默认 330°~30°，支持跨 0° 环绕）
- **Target Hue Tail**：目标范围边缘向内做平滑过渡（0~hr/2，hr 为目标范围跨度），避免边界生硬
- **Target Hue Pad**：向外扩展实际处理范围（0~hr/2），扩展部分同样平滑过渡

## 5. Preview 预览

- **Preview Type**：
  - `BothInLeft`（默认）：单窗口显示，默认显示处理结果，勾选 `Show Left Input` 显示输入
  - `SideBySide`：左右并排，左=输入、右=输出（`Show Right Input` 复选框当前禁用，右预览固定显示输出）
- **Preview Scale**（10%-100%，默认 50%）：预览缩放。调参时可调低提高响应速度，保存时按原始分辨率输出
- `Show Left Input` / `Show Right Input`：控制对应预览显示输入还是结果
- `Save Left Image` / `Save Right Image`：保存当前预览帧图像默认到 `Output Dir`
- 信息行：
  - `Display Size`（显示尺寸）
  - `Position`（鼠标位置，按空格可以冻结/解冻像素）
  - `Input Pixel` / `Output Pixel`（输入/输出像素读数）

**像素冻结**

- 鼠标在预览图上移动时，信息行实时显示该像素的坐标与 RGB/HSV 值
- 按**空格键**冻结：预览图上出现十字标记，信息行固定显示该像素读数，便于精确对比

## 6. 调试建议

### 6.1 各模拟对象方案的参数选择建议

| 模拟对象 \ 调色参数选择 | `Adjust Field` | `Contrast` | `Brightness` | `Saturation` | `Hue` |
| ------ | ----- | ---- | ---- | ---- | ---- |
| GIMP软件 **色相-饱和度** 工具 | `HSL` | - | `Rate2Limit` | `ModeMul` | `ModeAdd` |
| GIMP软件 **亮度-对比度** 工具 | `RGB` | `TanSlant` | `Rate2Limit` | - | - |
| GIMP软件 **饱和度** 工具 | `RGB` | - | - | - | `MixGray_BT601` |
| FastStone软件 **调整色彩** 工具 | `RGB` | `FastStone` | `ModeAdd` | `MixGray_BT601` | `ModeAdd` |
| dlib 图像处理算法库 | `HSI/HSL` | - | `ModeMul` | `ModeAdd` | `ModeAdd` |
| HISI ACM | `YCbCr` | - | `ModeAdd` | `ModeAdd` | `ModeAdd` |
| MTK SCE | `YCbCr` | - | `ModeAdd` | `ModeMul` | `ModeAdd` |
| RK ACM (YUV) | `YCbCr` | - | `ModeAdd` | `ModeAdd` | `ModeAdd` |
| RK ACM (RGB)(SW) | `HSV` | - | `ModeAdd` | `ModeAdd` | `ModeAdd` |

说明：

- 参考 “GIMP软件 **色相-饱和度** 工具” 调`Brightness`参数时，近白/近黑的像素的饱和度会被拉大，此为模型缺陷，这里暂未做修复
- 参考 “GIMP软件 **色相-饱和度** 工具” 对选定的六色之一进行调色时，影响范围都是60°，调`Hue`时每个色相旋转的角度保持一致

### 6.2 调试注释事项

1. **先用测试图**：按要验证的维度选图案——验证色调用 Rainbow 系列，验证饱和度用 Saturation Ramp 或 HSV Patches dS，验证明度/对比度用 Value Ramp 或 Gray Ramp，验证分区效果用 HSV Patches 系列
2. **处理域选择**：
   - 对RGB输入图像，希望采用通用的圆锥调色模型，则建议用 `HSV/HSL/HCY/HSP` 这几个模型；
   - 对RGB输入图像，希望计算代价小，则用 `RGB` 处理域
   - 对YUV输入图像，希望计算代价小且贴近 YCbCr 硬件语义，则用 `YCbCr` 处理域
3. **冻结像素精确对比**：把鼠标移到关注区域按空格冻结，对比 Input/Output 的读数，确认调整幅度是否符合预期
4. **从"小"到"大"调参**：先给较小调整量确认方向，再逐步加大；需要基准时用各通道的 `Reset` 回到中性值
5. **保护低饱和区域**：对肤色、灰暗区域做饱和度增强时，适当调大 `S Tolerance`，避免这些区域被过度增色
6. **指定色调边界**：先用 Tail/Pad=0 确认目标范围选择正确，再逐步加大过渡角度消除边界生硬感；跨 0° 的颜色（如红-品红）记得用环绕范围
7. **YCbCr 处理域**：调色后发现出现色相偏移现象，可在 `Y2Y Clip` 选择一种保色相策略（`ClipChroma`/`CompLumaOnly`/`CompLumaFirst`/`ScaleChromaPix`）后再观察

### 6.3 BCSH参数在不同模型和不同调整方法下的效果对比

| 调色模型 | 调色参数 | 调色方法 | 效果说明 |
| ------ | ------ | ------ | -------- |
| YUV(YCbCr) | `Brightness` | `ModeAdd` | 无法调到纯黑/纯白；Y越靠近黑/白，越容易偏色 |
| ^ | ^ | `ModeMul` | 无法调到纯黑/纯白；Y越靠近黑/白，越容易偏色；`db > 1`时会放大灰阶差异，可能引入等高线现象 |
| ^ | `Saturation` | `ModeAdd` | 尺度不统一，容易偏色，容易出现色块 |
| ^ | ^ | `ModeMul` | 尺度统一，但无法让所有颜色调满（也不建议调大倍率太大），**推荐** |
| ^ | `Hue` | `ModeAdd` | 标准做法，但从圆锥色相模型的角度来看比较容易发生色相偏移 |
| ^ | `Y2Y Clip` | `ClipChroma` | 保持色相(H)和亮度(Y)恒定，缩放Cb/Cr对应的极径 |
| ^ | ^ | `CompLumaOnly` | 保持色相(H)和色度(S)恒定（仍会因为y2r的钳位造成轻微偏色），但需要对亮度Y做补偿|
| ^ | ^ | `CompLumaFirst` | 保H、Y优先、S兜底：Y单独调不够时缩色度到r*并顶Y，色相严格保持、无残留越界，**推荐或可选实现**  |
| RGB | `Brightness` | `ModeAdd` | 加性，可以调到纯黑/纯白，但通道饱和后色相开始偏移 |
| ^ | ^ | `ModeMul` | 乘性，无法调到纯白，调大时色相会偏移，调小时不偏移 |
| ^ | ^ | `Rate2Limit` | 乘性，可以调到纯黑/纯白，**色相不偏移，推荐** |
| ^ | `Saturation` | `MixGray` | **尺度统一，严格不发生色相偏移，推荐** |
| ^ | `Hue` | `ModeAdd` | 转到HSV圆锥色相模型修改H，**色相不偏移，推荐** |
| ^ | ^ | `RotateOnGray` | 绕灰轴旋转，会色相偏移 |
| HSV | `Brightness` | `ModeAdd` | 可以调到纯黑，除黑色外无法变纯白，**推荐** |
| ^ | ^ | `ModeMul` | 可以调到纯黑，无法调到纯白 |
| ^ | ^ | `Rate2Limit` | 可以调到纯黑，除黑色外无法变纯白 |
| HSL | `Brightness` | `ModeAdd` | 可以调到纯黑或纯白；L接近黑/白时S会被病态放大（HSL 处理域的 S Tolerance 已按色度 $C=M-m$ 保护并对输出色度封顶） |
